01 · The brief

Honest reviews, one per student per course.

Students choosing courses rely on word of mouth. Faculty Reviews gives them structured ratings and discussion, with rules that keep it fair: one rating per student per instructor and course, and moderation built in.

  • Sign-up with a 5-digit ERP number, bcrypt-hashed passwords and 10-day tokens
  • Four 0 to 5 ratings per instructor per course, limited to one per student by a compound unique index
  • Threaded, optionally anonymous comments with upvotes and downvotes, one vote per user
  • A discussion feed with text search over posts, and saved comments, instructors and courses
  • User, Moderator and Admin roles enforced by the API

Key decisions

  1. 01Role checks live in the API (User, Moderator and Admin middleware on the routes), not only in the clients
  2. 02One rating per student, instructor and course, enforced by the database with a compound unique index
  3. 03Per-user vote lists on comments, so nobody can vote twice
  4. 04Comments and posts are soft-deleted, so moderation can be undone
